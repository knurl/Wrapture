# Wrapture

Wrapture is a small macOS app and Xcode Source Editor Extension for rewrapping Swift
comments.

It lets you choose a preferred column width, then use the Xcode extension to reflow
selected comments or the comment block around the insertion point. Wrapture is
intended for plain line comments and block comments, including documentation-style
comments.

## Support

Wrapture is provided as-is. No support, maintenance, troubleshooting, or feature
requests are promised or provided.

For App Store contact purposes, you can email: support@robanderson.online.

## Privacy

Wrapture does not collect, store, sell, or transmit personal data.

The app stores your preferred wrap length locally using Apple system storage. The
Xcode Source Editor Extension processes source text locally on your Mac in order to
rewrap comments. Source text is not sent to any server.

Wrapture does not use analytics, advertising, tracking, third-party SDKs, or cloud
services.
